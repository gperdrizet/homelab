    Homelab documentation¶

    Single source of truth for the machines, network, and services that make up the homelab. Published from the gperdrizet/homelab repository.

    Docs are organized service-first: each running service has a page naming its host, ports, ingress path, and repo. Machine pages cover hardware, OS, and platform posture only. Start with the service inventory.

    The machines¶

    Machine Role Docs
    gatekeeper IONOS VPS: public ingress, TLS, app hosting, monitoring, tailnet control Active
    pyrite ML/AI workhorse: inference, LiteLLM router, PostgreSQL, 15 TB storage Active
    ethics-gradient Desktop workstation; embedding + light utility inference Active
    the-educator Home theater PC; Minecraft server Active (stub)
    hugo Raspberry Pi 0 W; spare Active (stub)

    arkk (old NAS) was decommissioned; its 15 TB RAID5 now lives in pyrite and is documented under pyrite. Historical pages are in archive.

    Design principles¶

    • Private by default — services live on the tailnet; public ingress terminates on gatekeeper only.
    • Secrets stay out of git — .env.template committed, real values in Vaultwarden. See secrets management.
    • Docs track current state — inventory pages describe active infrastructure, not migration history.
    • Service pages name their host — services may move machines; the page travels with the service, not the directory.
